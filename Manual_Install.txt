HOW TO INSTALL

1. Extract HSEnhancer.zip and open the "Manual Install" folder.

2. Open the game folder:
   Right-click the game in Steam -> Manage -> Browse Local Files

3. For a standalone installation, place "winmm.dll" and "HSEnhancer.dll" in:
   <Game Folder>\HalfSwordUE5\Binaries\Win64

UE4SS USERS

Do not install "winmm.dll". Place "HSEnhancer.dll" in:
   <Game Folder>\HalfSwordUE5\Binaries\Win64

Place "main.dll" in:
   <Game Folder>\HalfSwordUE5\Binaries\Win64\ue4ss\Mods\HSEnhancer\dlls

Make sure ue4ss\Mods\mods.txt contains:
   HSEnhancer : 1

The launcher handles these UE4SS steps automatically.


HOW TO UNINSTALL

1. Delete the files you placed in the installation steps:
   - "winmm.dll"
   - "HSEnhancer.dll"
   - "ue4ss\Mods\HSEnhancer\dlls\main.dll" (UE4SS only)
   - remove "HSEnhancer : 1" from "ue4ss\Mods\mods.txt" (UE4SS only)
